# i18n — chuỗi UI và đối ứng locale

Quy ước này áp dụng cho **mọi người và agent** (Cursor, Claude Code, …) khi thêm hoặc sửa text hiển thị trên giao diện dashboard.

- Quy ước code tổng quát: [`AGENTS.md` §3.6](../AGENTS.md#36-ngôn-ngữ-ui-i18n)
- Kiến trúc frontend: [`architecture.md`](architecture.md)

---

## Nguyên tắc

1. **Không hardcode** chuỗi UI trong `.vue` / `.ts` — dùng `vue-i18n`.
2. **Luôn đối ứng đủ locale** khi thêm/sửa text: cùng key ở `vi` **và** mọi locale khác (hiện có `en`).
3. **`vi` là nguồn chân lý** cho cấu trúc message — locale khác phải cùng shape; thiếu key gây lỗi typecheck, không fallback runtime.
4. Chọn **namespace đúng feature** — không nhét text riêng feature vào `common` trừ khi thật sự dùng chung.

## Phạm vi áp dụng

Áp dụng khi thêm/sửa chuỗi **người dùng nhìn thấy**: label, nút, placeholder, tooltip, toast, thông báo lỗi, empty state, tiêu đề màn hình, v.v.

**Không cần i18n:** identifier kỹ thuật (task id, tên agent từ API), log nội bộ, comment code.

## Cấu trúc file

```
src/core/i18n/
├── index.ts
├── types.ts
└── locales/
    ├── vi/          ← locale mặc định, viết key ở đây trước
    │   ├── common.ts
    │   ├── monitor.ts
    │   └── …
    └── en/          ← cùng namespace, cùng key path
        ├── common.ts
        └── …
```

Namespace theo feature: `common`, `monitor`, `agentEditor`, `knowledge`, `runner`, `logs`, `pipelineEditor`, `quickAction`, `settings`, `notifications`.

## Cách dùng trong code

| Ngữ cảnh | Cách gọi |
|---|---|
| Trong `<script setup>` | `const { t } = useI18n()` → `t('namespace.key')` |
| Ngoài component (vd `src/api/`) | `i18n.global.t('namespace.key')` |
| Test component có `t()` | `mountWithI18n` (`tests/src/helpers/i18n.ts`) |

Locale người dùng chọn lưu trong `AppSettings.locale` (localStorage); đổi qua `useLocale()`.

## Checklist khi thêm/sửa text

1. Xác định namespace feature phù hợp.
2. Thêm key vào `src/core/i18n/locales/vi/<namespace>.ts`.
3. Thêm **cùng key path** vào `src/core/i18n/locales/en/<namespace>.ts` (và locale khác nếu có).
4. Thay hardcode trong component/composable bằng `t(...)`.
5. Chạy typecheck — thiếu key ở locale phụ sẽ báo lỗi.

## Ví dụ

```vue
<!-- ❌ Không làm -->
<button>Lưu</button>

<!-- ✅ Đúng -->
<button>{{ t('common.save') }}</button>
```

```typescript
// locales/vi/common.ts
export const common = {
  save: 'Lưu',
  // …
};

// locales/en/common.ts — cùng key path
export const common = {
  save: 'Save',
  // …
};
```
