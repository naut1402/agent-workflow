# i18n — chuỗi UI và đối ứng locale

Quy ước này áp dụng cho **mọi người và agent** khi thêm hoặc sửa text hiển thị trên giao diện dashboard.

- Quy ước code tổng quát: [`AGENTS.md` §3.6](../AGENTS.md#36-ngôn-ngữ-ui-i18n)
- Kiến trúc frontend: [`architecture.md`](architecture.md)

---

## Nguyên tắc

1. **Không hardcode** chuỗi UI trong `.vue` / `.ts` — dùng `vue-i18n`.
2. **Luôn đối ứng đủ locale** khi thêm/sửa text: cùng key ở `vi` **và** mọi locale khác (hiện có `en`).
3. **`vi` là nguồn chân lý** cho cấu trúc message — locale khác phải cùng shape; thiếu key gây lỗi typecheck.
4. Chọn **namespace đúng feature** — không nhét text riêng feature vào `common` trừ khi thật sự dùng chung.
5. Cài đặt thư viện qua **`src/plugins`** (`installPlugins` / `i18nPlugin`) — không `createI18n` rải rác trong feature.

## Cấu trúc file

```
src/plugins/
├── index.ts                 # installPlugins(app)
└── i18n/
    ├── index.ts             # i18nPlugin, injectI18nHelpers, registerLocale, setI18nLocale
    ├── loadLocales.ts       # glob feature + plugin locales
    ├── schema.ts            # Messages (vi) + kiểm type en
    └── locales/common/      # namespace shell dùng chung
        ├── vi.ts
        └── en.ts

src/features/<feature>/locales/
├── vi.ts                    # export default { ... }  (namespace = camelCase tên feature)
└── en.ts
```

Ví dụ: `features/agent-editor/locales/vi.ts` → namespace `agentEditor`.

Plugin tự nạp bằng `import.meta.glob` — feature mới chỉ cần thêm `locales/vi.ts` (+ `en.ts`) và khai báo namespace trong `schema.ts` (để typecheck).

## Đăng ký locale mới (runtime)

```ts
import { registerLocale } from '@/plugins/i18n'

registerLocale('ja', {
  common: { /* ... */ },
  monitor: { /* ... */ },
})
```

`registerLocale` merge vào vue-i18n và cập nhật `getLocaleRegistry()` (inject app-scope qua `I18N_REGISTRY_KEY`). Locale preference persist vẫn theo `AppSettings.locale` — mở schema `LocalePreference` nếu thêm mã locale cố định vào Settings.

## Cách dùng trong code

Plugin chỉ được gắn từ app root:

```ts
// src/main.ts
installPlugins(createApp(App), { i18n: { locale } }).mount('#app')
```

`i18nPlugin` inject helpers lên Vue app (`$t` qua vue-i18n, kèm `$setI18nLocale` / `$localeRegistry`). Feature lấy qua instance:

| Ngữ cảnh | Cách gọi |
|---|---|
| Trong `<script setup>` / composable | `const app = useApp()` rồi `app.$t('…')` (**cấm** `import { useI18n } from 'vue-i18n'` ngoài `src/plugins`) |
| Template | `$t('…')` (globalProperties) |
| Ngoài setup (scripts / pure fn) | `import { t } from '@/plugins/i18n'` — đọc `$t` trên app sau `installPlugins` |
| Đổi locale | `useLocale()` hoặc `app.$setI18nLocale` |
| Test component có `$t` | `mountWithI18n` (`tests/src/helpers/i18n.ts`) — cài cùng globalProperties |

## Checklist khi thêm/sửa text

1. Xác định feature / namespace.
2. Sửa `src/features/<feature>/locales/vi.ts` (hoặc `plugins/i18n/locales/common/vi.ts`).
3. Đối ứng cùng key ở `en.ts`.
4. Feature/namespace mới: thêm import vào `src/plugins/i18n/schema.ts`.
5. Thay hardcode bằng `t(...)` / typecheck.
