# Quy ước — i18n (chuỗi UI và locale)

Áp dụng khi thêm hoặc sửa text hiển thị trên giao diện dashboard.

1. **Không hardcode** chuỗi UI trong `.vue` / `.ts` — dùng `vue-i18n`.
2. **`vi` là locale mặc định + fallback** (`fallbackLocale: 'vi'`). Locale khác (vd `en`) thiếu key thì hiện bản tiếng Việt — không ép typecheck đối ứng đủ key.
3. Khuyến nghị vẫn viết `en` khi thêm text mới (UX), nhưng thiếu không chặn build.
4. Chọn **namespace đúng feature** — không nhét text riêng feature vào `common` trừ khi thật sự dùng chung.
5. Cài đặt thư viện qua **`src/frontend/plugins`** (`installPlugins` / `i18nPlugin`) — không `createI18n` rải rác trong feature.
