# Release 1.0.2

So với **1.0.1** / `main` trước merge (PR [#189](https://github.com/naut1402/agent-workflow/pull/189), roadmap [#188](https://github.com/naut1402/agent-workflow/issues/188)).

Phiên bản `package.json`: **1.0.2**.

Không gồm scope **1.1.0** (event bus, webhook, token usage UI, clone/branch, knowledge scan/version). Không gồm Docker bun scripts (đã revert — sai scope).

---

## Tính năng (Features)

### Runner — Agent CLI & connection

- Tách `AgentCliProvider` / `providerFamily` (`agent-cli` vs console-command / AI API); Claude / Cursor / Codex dùng chung nền agent-cli.
- Không cho gán **console-command** làm runner AI mặc định (validate registry + UI).
- **CRUD custom command** (persist + API + UI), danh sách command đồng bộ kiểu connection, tránh trùng tên.
- UI **sửa / xoá connection** (icon-btn theo [`docs/ui-buttons.md`](../ui-buttons.md)).

### Monitor & job log

- Đọc **transcript Cursor** + **session ledger per-step**; UI báo lý do khi thiếu transcript.
- Làm giàu **metadata job log** (header/footer: job / task / step / session / provider).

---

## Sửa lỗi (Fixes)

- Chat task: **fallback** nội dung từ job stdout/log khi thiếu transcript Cursor.
- Ghép **timeline chat** từ mọi job feedback của step (không bỏ sót feedback phụ).
- NL chat FE: **full refresh** khi còn pending — hết kẹt trạng thái «Đang gửi».
- Test / e2e: aria-label nút thêm connection; expect transcript + `supportsTokenUsage=false` (token usage chưa ship 1.0.2).

---

## Tài liệu (Docs)

- Quy ước **tách commit theo từng xử lý** (`docs/implement/git-convention.md` §6; trỏ từ PR/commit convention).

## Breaking changes

Không có.

**Hành vi đáng chú ý (không breaking API):** runner mặc định không còn chấp nhận console-command; cần chọn provider agent-cli / AI hợp lệ.

---

## Ghi chú kỹ thuật (ngắn)

- Refactor nền: `business/providers/agentCli.ts`, `jobLogFormat.ts`; Cursor qua `cursorSessionTranscript.ts` + dispatch `taskChat`.
- API runner: endpoint CRUD command + sửa/xoá connection.
- `supportsTokenUsage` vẫn `false` ở 1.0.2 — không advertise usage UI.
